# CE / NPG 按论证点补实验：完整结论（2026-10-28）

**补跑、结果审核和三张组合图均已完成。** 主结论是：CE 的维度收益很清楚；
NPG 的同系统收益、冗余噪声机制及满秩有效秩权衡都有实质证据，
但本轮固定排程在部分高维/高秩单元失稳，不能宣称已验证普遍的 rn²/epsilon 样本斜率。
平坦谱和较大谱尾给出了明确的截断有害对照。

逐稳定策略计算 D(K)=J(K)-J(Pi_R K)，以及 g(Pi_R K)，核对 g(K)=D(K)+g(Pi_R K)。
全量记录中的最大按 max(1,J) 归一化分解残差为 **2.36e-12 以下**。
绝对残差最大约6.82e-5，发生在大代价策略上，不能与归一化残差混用。

**CE：同一完整估计隔离截断的作用。** n24/r2、N=3,072、标量 A 下，
配对总 gap 下降中位数0.093455、配对 D 下降中位数0.093085，二者很接近；
有效部分变化较小。耦合 A 相应为0.088137与0.087734。
这些是分别对每个配对先计算再取中位数，不能要求几个中位数精确相加。
截断策略的真实 D 非零，估计空间不是实际输入子空间。

**NPG：共同 K0、共同 blocks、同一 Zhat 的单步对照。** n24/r2、标量 A：

|---|---:|---:|
|下一步 gap 中位数|3.511084|1.241032|
|下一步真实 D 中位数|2.647419|0.711578|
|critic Frobenius 误差平方中位数|174.7043|49.9158|
|critic operator 误差中位数|5.1746|5.1707|

耦合 A 下下一步 D 从2.672664降至0.716281，Frobenius误差平方从177.4723降至50.1137。
operator误差几乎没有同幅度下降，不能混用两种误差尺度。
这是截断相对 dense 的单步改进，并不意味着两种噪声更新都相对 K0 下降。

## 图 3：满秩、有效秩、平坦谱与 adaptive CE

本轮满秩 NPG 共1,032条，全部稳定；所有k在同一系统、同一预设累计预算内比较。
经验最佳固定 k 是离线诊断，不是给学习器的 oracle，也不是自适应 NPG。

|A|满秩谱|最大预算 Dense gap|经验最佳 k|最佳固定 gap|
|---|---|---:|---:|---:|
|0.5I|两段谱，delta=.05|0.073463|2|0.045105|
|耦合 A|两段谱，delta=.05|0.069929|2|0.042936|
|0.5I|平滑谱 .7^j|0.066909|8|0.061991|
|耦合 A|平滑谱 .7^j|0.066462|8|0.061140|

NPG 两段谱在有限样本下确实存在较小 k 优于 dense。
平滑谱的预算检查点 M=0.296784/1.478304/6.198768/25.075008 百万时，
两类 A 的经验最优 k 都按 **0→1→3→8** 移动。
两段谱标量 A 是0→1→1→2，耦合 A 是0→1→2→2。
低预算最优k0说明不更新可优于很噪声的学习更新，不是无样本学得了最优策略。
平滑谱最终 k8 相对 dense 只低约7%–8%，不夸大为显著、普遍的大幅收益；
固定过小的 k 在高预算会保留明显误差，不能将固定k2/k4当成通用选择。
上述 M 变化也伴随优化阶段变化，不单独识别纯估计噪声缩放。

**Adaptive CE 的经验收益与局限同时存在。** 平滑谱 N=1,024、标量 A 时，
dense gap0.146664，最佳固定k6为0.117972，adaptive为0.119621。
所选秩中位数随预算由3增至11；同谱经验最佳固定秩最终达到16。
两段谱 N=16,384 时，adaptive gap0.017727仍高于dense的0.009101；
最高预算选16阶后接近dense。
阈值常数c=1预先固定，使用 split disagreement 代理；没有逐系统按真值调参。
这不是已验证的理论LS置信半径，不能据此声称逐点oracle最优。

**平坦谱是明确的负对照。** 各方法在自己的最大预算下：

|算法|Dense gap|k2 gap|k8 gap|稳定性|
|---|---:|---:|---:|---|
|CE|0.001327|2.807930|1.605219|各臂24/24稳定|
|NPG|0.042792|1.232455|0.132734|各臂24/24稳定|

CE 的 adaptive 在该点保留全16阶，与dense结果相同。NPG k2约为dense的28.8倍gap，
k8也较差。强截断收益依赖有效低秩，不能推广到平坦谱。
CE总预算65,680，NPG总预算25,075,008；本表不用于跨算法快慢比较。

**尾强度对照。** [对数横轴附图](../local_runs/ce-npg-arguments-20261028/report/appendix_tail_strength.png)
固定 k2、n16，tau_2²=14 delta²；所有末端比较均24/24稳定。

|delta|tau_2²|CE dense / k2 gap|NPG dense / k2 gap|
|---:|---:|---:|---:|
|.01|.0014|.002325 / .001318|.073804 / .030256|
|.05|.0350|.002284 / .021111|.073463 / .045105|

尾部增大后固定低秩的残余损失增大，足够大时两条路线都被dense反超。
这是有限预算的权衡；没有证明某个NPG population参考已收敛到唯一误差floor，
也不将B的尾部数值等同于每个当前策略Z_K的尾部。

## 稳定性、统计解释与论文边界

228条失稳全部来自exact-rank NPG：dense163条、truncated65条。
失败以后所有计划预算继续计失败；没有删除、自动重跑、补种子或真值选迭代。
全量NPG 1,608条均核对了49个计划阶段及失败吸收规则。

另有498条NPG轨迹至少一个已评价稳定阶段违反 P_K<=2P_K0。
因此本实用冻结排程不能被写成逐条件实现了正文 all-prefix 矩阵包含保证；
Schur稳定不等于满足该矩阵条件，经验失稳也不构成理论定理的反例。

有限配对倍率和bootstrap带是描述性量。只有3个系统种子；
幸存者倍率不能替代全分母表现。耦合A、n24/r4仅1对稳定配对，
程序给出的退化bootstrap百分位值不作为总体置信区间或显著性证据。
本轮未新增PI学习；与正文实现匹配的历史PI只作附录证据，参见
[既有PI与正文实现说明](PROJECT2_OVERNIGHT_FINDINGS_20261020.md)。
问题类下界仍是理论比较基准，没有“有限实验验证所有算法minimax下界”的图。
