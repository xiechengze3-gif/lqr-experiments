## 原版 K0 不只是有方向线索

G02 的主 `coupled_unstable` exact-rank 构造为

\[
B=U_r\operatorname{diag}(s_i)V_r^\top,\qquad
K_0=V\operatorname{diag}(k_i)U^\top,
\quad k_i=.4/s_i\ (i\le r),\quad k_i=.03\ (i>r).
\]

由于前 r 个 k_i 都大于尾部的 .03，K0 的主 r 维左奇异空间就是真实输入空间。在知道生成规则的情况下，甚至有

\[
\boxed{B=.4\,[T_r(K_0)]^\dagger.}
\]

因此，原版主族把需要学习的 B 编码进了给定的 K0。上述完整 B 恢复公式针对共用左右基的主 coupled 族；独立左基验证变体仍暴露 B 的输入行空间，但不能套用这个完整恢复公式。实际 learner 没有调用该恢复公式，不改变初始条件已包含额外信息这一事实。

## Isotropic 修改消除了什么

G03 的 K0=.35 VU' 满足 K0 K0'=.35² I，全部奇异值相等，因而不能通过“取 K0 前 r 个奇异向量”选出真实 r 维方向。这一修正确实消除了原版的直接谱线索。

但它仍与 B 共用 U/V，并满足额外关系

\[
BK_0=.35\,U_r\operatorname{diag}(s_i)U_r^\top\succeq0.
\]

任意独立随机 K0 与 B 通常没有这个对称半正定乘积关系。加上 A=F0+B0K0，系统是按指定稳定闭环倒推出来的。**“K0 没有可辨识的主 r 子空间”与“K0 独立于真模型、A/B 没有联合构造”是不同条件，前者通过，后者没有通过。**

G04/G05 的 K0 也有相同的共基关系。它们固定 A、K0 再改变 B 的谱，有利于隔离 rank／tail，但 A 的特定状态基、不稳定方向布局与 B 仍共享设计。

## Matched-gap 初始化的实际几何信息

对保存的系统矩阵直接重新计算 K0 的主左奇异子空间与 B 输入行空间的平均重合度：

\[
\mathrm{overlap}=\|\widehat V_r^\top V_r\|_F^2/r.
\]

这里四组均 Q=R=I，B 的输入行空间也就是相应有效动作空间。重合度衡量两个子空间，不是 K0 的总能量比例。

| rank2 系统 | K0 与 Kstar 的扰动尺度 alpha | K0 主2维与真实输入空间重合度 | 无方向信息的随机2维空间平均参照 |
|---|---:|---:|---:|
| matched-gap 100d | .0877705 | **95.96%** | 2% |
| 原 matched-gap 500d | .0397282 | **98.74%** | .4% |
| 等模态 500d | .0397863 | **99.75%** | .4% |
| independent random-A 500d | .0258521 | **99.90%** | .4% |

四组保存的 delta=K0−Kstar 都满足 delta delta'=alpha²I；相对残差约 1e-15。它们确实来自 Kstar 加正交扰动，而不是一般的独立随机初始稳定策略。满秩 K0 仍可保留非常清晰的真实低维子空间。

random-A 系统文件中保存的 `K0_original=0` 只是构造时的参考证书。实际采样 runner 读取的是后面写入的 `K0=Kstar+alpha D`，不能据 `K0_original` 字段宣称已经做过 K0=0 的该组学习实验。

## A 和 B 的特殊关系

**原 100d／500d rank-sweep 家族**并不是只对 B 施加 rank 条件。它在某个随机旋转坐标下有

\[
U^\top AU=\begin{pmatrix}1.2&0\\0&T\end{pmatrix},
\qquad U^\top BV=b\operatorname{diag}(I_r,0),
\]

其中 T 预先稳定，唯一的精确不稳定特征方向 u1 始终被 B 覆盖。保存矩阵中 A u1=1.2u1 的相对残差约 1e-16。matched-gap 修改了 K0，没有改变这套 A/B；100d 原版与 matched 版逐 rank 的 A/B 字节 hash 相同。

**500d 等模态族的结构更强。** 它满足

\[
U^\top AU=\operatorname{diag}(1.2I_r,.45I_{n-r}),\qquad
U^\top BV=\operatorname{diag}(I_r,0),\qquad Q=R=W=I.
\]

换坐标后，是 r 个相同、彼此解耦的受控标量问题，加 n−r 个稳定、无直接控制的标量问题。A=.45I+.75BB' 的保存矩阵相对残差约 1e-17。随机旋转使原坐标矩阵稠密，但没有增加这种系统的动力学耦合。该族的 47 倍结果应视为这种结构化族的结果。

**random-A 500d 在 A/B 方面确实不同。** A 与 B 使用独立随机源；同一 A 在五个 rank 上逐字节相同，A 没有按 B 的子空间重新设计。它可以作为排除上述 A/B 对齐机制的补充。剩余问题是初始化仍用了 Kstar，而且给出 99.90% 的主子空间重合度。

B 本身通过指定奇异值／rank／tail 来生成，是研究低秩所需的实验设定；需要特别标出的额外条件，是 A 与 B 的共同基、不稳定块对齐、强谱间隙，以及 K0 对真实 B 或 Kstar 的依赖。这些都不能由“矩阵每个元素非零”来排除。

## 按原文固定系统常数的构造与推荐

**更正上一答的解释重点。** TR 的“Why the nuisance matrix A does not force an n² term”段明确说明：A 用 operator norm 估计，整体策略误差通过低秩结构转换为 Frobenius 误差；CE 的最终控制样本复杂度为 O_sys(r(n+m)/epsilon)。Ahat 的全矩阵 Frobenius 误差既不是这个结论的估计目标，也不是系统常数，不能用它替代对论文系统参数的核查。上节 Ahat/Bhat 数值仍是描述性诊断，不构成对 r(n+m) 结论的解释或反例。

v4 第 1 节约定，系统常数只依赖 (q,mu_±,w_±,b_B,p0,nu)。TR §4.1 的 L_A、L_B、C_Sigma、h_star 的上界与 CE 激励常数，也都可由这些共同标量及共同 K0 的范数确定。这里最需要控制的是 P_K0 的谱上界 p0，而不是把不同 rank 的初始 gap 强行调齐。

### 一、保留现有独立 Gaussian A/B 的共同稳定器

先独立生成 A 和左右正交基 U/V，令 B_r=U_r V_r^T，r=2/4/8/32/500。所有 rank 使用同一个 A 和嵌套 B；每个 B_r 与 A 的独立性保留。给定最小 rank=2 的稳定器 Ktilde，取

\[
K_c=V_2V_2^\top\widetilde K.
\]

对任意 r≥2，B_r V_2V_2^T=B_2，因此

\[
B_rK_c=B_2\widetilde K,\qquad F_c=A-B_rK_c
\]

跨 rank 完全相同。固定 Q/R 后，S_c=Q+K_c^T R K_c 相同；Lyapunov 方程的唯一解 P_c=S_c+F_c^T P_c F_c 也相同。该构造不使用 Kstar，不反向生成 A，也不调初始 gap。它是所有 rank 共用的一个稳定器，不再按 rank 分别做极点配置。

Grace 作业 20254006 已验证这一路径：5/5 通过，rho(A)=1.05，rho(F_c)=.9946389643，P_c 的谱范数约 35498.47018；跨 rank 独立求解的 P_c 最大相对差异 8.46e−13。原 A/B 的数组 hash 保持不变。此例证明共同证书可以做到，但共同 p0 仍大，因此推荐下面更适合采样的谱受控版本。

### 二、推荐的谱受控、A/B 独立版本

固定 n=m=500。使用独立于 B 的随机源生成正交基 O，令

\[
A=O\operatorname{diag}(1.05,\lambda_2,\ldots,\lambda_n)O^\top,
\qquad \lambda_i\in[-.55,.55].
\]

B 仍用前述独立随机 U/V 生成 B_r=U_r V_r^T；A 的不稳定方向不按 B 重新选择。取 A 的单位不稳定特征向量 u，令 v=B_2^T u、gamma=1.05−.9=.15，并取所有 rank 共用的

\[
K_c=\gamma\frac{v u^\top}{\|v\|^2}.
\]

由于 v 位于 B_2 的输入空间，所有 r≥2 都有 B_r v=B_2 v，故初始闭环相同。并且 u^T F_c=.9u^T，u 的正交补空间在 F_c 下保持不变，其特征值为 lambda_2,...,lambda_n；因此 rho(F_c)=.9。这里的共同 K0 为 rank1，其输入方向来自最小 rank 通道；这是控制系统常数的明确设计条件。初始化只做固定极点稳定化，不使用任务最优策略或代价优化。

Q=R=W=I、nu=2，所有 B_r 的非零奇异值均为1。Grace 作业 20254208 在真实节点 c124 完成，5/5 通过：

| 跨 rank 固定的量 | 实测／供给值 |
|---|---|
| rho(A) | 1.05 |
| rho(A−B_r K0) | .9 |
| Q、R、W | I |
| q、mu_±、w_±、b_B | 全为1 |
| nu | 2 |
| ||K0||op | 1.8722155659 |
| ||P_K0||op | 46.5299242321 |
| 统一供给的保守 p0 | 47 |
| K0、F0、P0 | 所有 rank 共用相同矩阵 |

独立求解的 P_K0 跨 rank 最大相对差异为 9.45e−14，Lyapunov 相对残差小于 9.37e−15。按统一 p0=47 计算，chi=94，NPG 的理论步长可统一取 1/95。CE 的局部半径、L_A/L_B、激励门槛上界，以及 Stein 的稳定区域／H／精度日程常数，都可以使用同一套系统标量。

### 共同证书究竟固定了什么

之前“系统常数都一样”的准确含义是：论文的供给界(q,mu_±,w_±,b_B,p0,nu)相同，K0/F0/P0也相同，从而能够使用同一个理论误差上界系数。它没有使所有实例的实际识别协方差、最优Riccati解或控制误差敏感性相同。

原文[TR CE 定理](C:/Users/24375/Desktop/project2_technical_report.tex:759)给的是

\[
J(\widehat K_r)-J_r^\star\le C_{\rm sys}\,r\,a_N^2,
\qquad a_N^2\lesssim_{\rm sys}(n+m)/N.
\]

相同的 C_sys 给出了统一的充分样本上界 O_sys(r(n+m)/epsilon)，并不把每个固定实例的最小达标N约束成同一个常数乘r，也不推出不同r之间的实际达标N必然单调。要用这条构造展示紧的线性r曲线，还需要其实际局部风险系数大致随r增长；仅固定供给证书不能保证这一点。

本构造中存在两个可直接推导的实际变化：

1. 探索系统为 x_{t+1}=F0*x_t+B_r*xi_t+w_t，xi协方差4I，w协方差I。其平稳协方差满足 Sigma_x,r=F0*Sigma_x,r*F0^T+I+4B_rB_r^T。嵌套B_r的 B_rB_r^T=U_rU_r^T 随r按PSD序增加，所以实际Sigma_x,r也按PSD序增加。回归联合协方差为 T*diag(Sigma_x,r,4I)*T^T，T=[[I,0],[-K0,I]]相同；其逆协方差随r按PSD序减小。因此同一个共同激励下界并未固定实际OLS误差分布。
2. 增加嵌套输入通道后，较小rank的控制器可以原样嵌入较大rank系统：B_r V_sV_s^T=B_s（r≥s），控制代价保持。因此最优Pstar_r按PSD序不增，但共同P0固定。这个证书可以在较大rank上变得更保守；真实Riccati敏感性和Hstar=I+B_r^T Pstar_r B_r无需相同。满秩时A对称、B正交，Pstar的最大特征值可解析计算为(1.05^2+sqrt(1.05^4+4))/2=1.693124，明显小于共同p0=47。这里给的是解析值，新增机制数值作业尚未执行。

这些变化都来自有效的独立A/B嵌套构造，并非A由B反向生成，也不涉及Kstar初始化。它们意味着当前构造满足统一定理条件，却没有自动成为每个rank都同样困难的实例族。
