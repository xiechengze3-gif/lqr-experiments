# Project 2 (L4DC 2027): agent conventions

This folder is the LaTeX source of a single-author L4DC 2027 submission
(Chengze Xie) on learning LQR with effective actuation rank.

- Build: `main.tex` with `l4dc2027.cls` (pdflatex -> bibtex -> pdflatex x2).
- Main text: `sections/01-intro.tex` ... `07-conclusion.tex`. **Do not edit
  the main text** unless a task file explicitly says so.
- Appendix: `sections/appendix.tex` inputs `sections/app/*.tex`.
- Source of all mathematics: `reference/project2_technical_report_2026-10-25.tex`
  (the "TR"). Never introduce a result that is not proved there; if a
  main-text statement cannot be proved as stated, report it instead of
  changing it.
- Citations: use only keys already in `refs.bib`. Do not add new
  references (every reference must be verified online by the author).
- Never push to git or Overleaf.
- Codex inbox: `codex/TASK.md` (rounds, protocol, writing standard).
  Codex replies by appending to `codex/REPLY.md`. Check `codex/TASK.md`
  regularly for new or revised rounds.
