# 已完成 CE 的选图意见

本文件依据 X1/X2/X3 的正式 CSV；actor 结果仍在运行，不以 pilot 代替正式结果。只给论文编辑建议，不修改任何 TeX。

- **X1 归一化冗余代价适合主图。** `X1/report-ce-v2/normalized_N8192` 按每个 system/seed 先算 ND/v_star，再取中位数和 IQR；非零 null 家族在 m>r 上匹配初始成本。8192 前缀全部稳定，4096 前缀的15个失败输出保留。m=r 必须标为单独的零 null 基线。
- **X2 维数/秩扫描适合完整表格，不能写成普遍 n/r 实验定律。** 同一系统内的 dense/truncated 比较有意义；不同 n/r 的系统有不同初始成本与条件数。n96 最大预算 dense28/32 稳定、截断32/32；绝对/相对精度的56项中仅17项达到预设29/32标准，其余39项右删失。
- **X2 固定预算比值图应带有限配对数和失败率。** `X2/report-ce-v2/fixed_budget_ratios_clean` 已给出 N/d=16/64/256 的中位数和系统 bootstrap 区间；部分高维单元仅16/32有效配对。这是有限配对诊断，不能掩盖失败或直接据此宣称稳健样本复杂度增益。绝对与相对比值相同，是同一配对初始 gap 抵消的结果。
- **X3 固定秩包络和最佳保留秩适合说明偏差与估计误差的权衡。** 平滑谱总体随预算保留更多秩，两层谱由低秩转向满秩，平坦谱负对照始终选择满秩。实际最佳秩并非严格单调。包络是固定 k 的组中位数的事后诊断，不能称为在线可用策略。
- **X3 自适应阈值不适合宣传为普遍优于 dense。** n32 两层谱最大预算的论文阈值方法31/32稳定、gap中位数7.41064；dense32/32、0.906282；split32/32、2.05967。两种自适应方法的偏差都要如实讨论。
- **X3 的 k=0 只放诊断行。** 3456/3456均失败，属于 r>=1 定理范围外；其余学习输出的失败是2291/38016，不能把5747总数全部称为学习算法失败。
- **稳定区间图不能替代完整网格。** `X3/report-ce-v2/stable_region_n16/n32` 仅显示 dense、两个 adaptive 和所选固定秩包络均32/32稳定的前缀。n32两层谱的最大两个前缀被这一显示规则排除，必须同时引用完整网格和失败热图，不能据裁剪视图声称所有高预算迭代稳定。

算法版本统一为正文单轨迹、512步探索 burn-in 的原坐标 OLS CE；各方法共享同一拟合，固定秩只截断 Bhat。所有新结果使用独立生成、开环不稳定的 A/B 和不调用成本的稳定化初始控制器。真子空间 oracle 仅作 X1 诊断。LSTD-PI、critic 或与该采样流程不同的历史结果不混入这些主图。

建议的定理关系表述：这些是 pilot 校准的有限预算，没有按理论高概率镇定结论所需的全部充分常数配置排程。实验保留了有限预算失败，不能把它们描述成满足全部定理条件后的反例；也不能据成功单元声称已经数值认证了理论常数。NPG 单独报告配对相对比较，不预先宣称达到 epsilon。

数据入口：各实验 `report-ce/all_statistics.csv`、`report-ce/paired_bootstrap_effects.csv`、`report-ce-v3/failure_by_n_spectrum_method_k_N.csv`；X2 另有 `budget_to_epsilon.csv`，X3 另有 `fixed_k_envelope.csv` 和 `spectral_tails.csv`。完整原始结果交付通过逐文件哈希；旧178文件保持不变。
